전략 설명

현재 기준형과 과거 시안의 조건을 구분해 확인하세요.

Pine 파일은 후보 신호를 표시하는 indicator입니다. 실제 거래·손절·복리 결과는 Python 백테스트와 거래 기록을 따릅니다. 최신 지지·저항 규칙은 아직 Pine에 포팅되지 않았으며 TradingView 컴파일 검증도 별도입니다.
Pine 코드 보기거래 차트 검토

실험과 결과

실험 목적 → 조건 설명 → 상세 결과 → 거래 차트 순서로 검토할 수 있습니다. 과거 보고서의 기준형·이름은 당시 기록을 유지합니다.

통계·그림 모아보기

색으로 표현한 비교 통계, 승률·손익비, 잔고·낙폭 곡선과 검토 화면을 모았습니다. 그림을 누르면 확대하고, 관련 보고서에서 조건과 수치를 확인할 수 있습니다.

차트 검토 화면 캡처

당시 브라우저 검토 화면입니다. 최신 거래 위치와 전체 구간은 차트 메뉴에서 확인하세요.

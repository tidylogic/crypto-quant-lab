# 추세·거래량 전략: 순차 지지·저항 확인

사용자 지정: 신호가 나온 주기의 SMA20/50/100/200을 사용하고 진입 확인은1분봉으로 통일한다. 진입 전20실패→50→100→200 대기와, 실제 진입 후 손절→다음 선에서 재진입을 모두 비교한다. 보유 중 최근접 지지·저항 실패 청산도 비교한다. 기존 기준형은 바꾸지 않는다.

고정 비교군:

|코드|진입|추가 청산|
|---|---|---|
|B0|기존 G 신호 다음 신호 주기 봉 시가|기존 SMA50 종가 실패|
|N0|기존 G 신호 즉시|최근접 지지·저항 실패|
|W0|신호 후 순차 지지·저항 확인, 신호당1회|진입 근거 이평선 실패|
|W1|W0와 동일|최근접 지지·저항 실패|
|R0|W0 + 손절 후 다음 선에서 **새 G 신호**를 기다림|진입 근거 이평선 실패|
|R1|R0와 동일|최근접 지지·저항 실패|

G 신호는 기존 이중 Stochastic 새 교차·완전 SMA 정/역배열·MFI14 롱>50/숏<50·이전20봉 RVOL≥1.2를 그대로 사용한다. 진입을 확정할 때도 완전 정/역배열이어야 한다. 모든 방식은 반대 원시 지표 교차 청산을 유지한다.

사용자의 후속 지정에 따라 이평선 실패 청산은 **1분 마감 vs 신호·이평선 기준 타임프레임 마감**으로 나눈다. 고정5분이 아니다. B01개 + 나머지5개×확인주기2개=11개다. 확인 주기는 실패 검사와 보호 선 갱신에 함께 적용한다. 반대 지표 교차와 첫 봉S2 가격 손절은 각자 기존 주기로 유지한다.

실험값은 성과를 보기 전에 고정한다. 허용 폭은 신호 당시 ATR14의0.1배, 대기 유효기간은 신호 주기3봉이다. 다음 선 재시도 연결도 손절 후3봉까지만 유지하며 해당 방향 배열이 깨지면 초기화한다. 이 숫자는 검증 시작값이며 최적값이라는 뜻이 아니다.

롱은1분봉 범위가 이평선±허용 폭과 겹치고, 종가≥이평선+허용 폭이며 양봉일 때 지지 회복으로 본다. 숏은 종가≤이평선−허용 폭·음봉으로 대칭이다. 실패는 롱 종가<선−폭/숏 종가>선+폭이다. 신호가 확정된 뒤 시작하는1분봉부터 확인한다. 한1분봉에서 여러 선이 실패하면 마감 시 다음 유효 선으로 이동하되, 같은 봉의 과거 고저가를 새 선 지지로 재사용하지 않는다. 이평선은 해당 시각에 이미 마감한 신호 주기 봉 값만 사용한다.

진입 전에는 신호 유효기간 종료·반대 교차·배열 파괴·200선 실패로 취소한다. W는 새 신호마다20부터 다시 확인하며, R은 손절 시 실패한 보호 이평선의 다음 선부터 새 신호를 기다린다(S2 가격 손절 포함). 단, 배열이 깨진 방향의 재시도 연결은 유지하지 않는다. 반대 방향의 새 신호는 이전 포지션의 실패 선을 이어받지 않는다. **동일 신호 재사용만으로 재진입하지 않는다.**

최근접 보호 선은 가격의 지지 쪽(롱 아래)/저항 쪽(숏 위)에 있는 가장 가까운 선이다. 한 번 선택한 보호 선이 실패했는지 먼저 검사하고, 통과한 뒤 더 가까운 새 선으로 보호를 올린다. 실패한20을50으로 바꿔 손절을 회피하지 않는다. 보호 가격은 불리한 방향으로 완화하지 않는다. 초기 신호 진입에 적절한 지지·저항 선이 없으면200선 기준을 사용하고 별도 집계한다.

일반 체결은 확인 종가 다음1분봉 시가다. 별도 첫 봉1% 가격 손절(S2)은 모든 비교군에서 유지하며 **실제 진입이 포함된 신호 주기 봉**이 끝나면 취소한다.1분봉 내부 손절은 고저가·시가로 검사하고 갭은 시가를 반영한다. 정확한 초단위 체결 순서는 추정하지 않는다. 원래 신호 주기 OHLC만으로 S2를 계산한 결과와 갭·현금 이용 가능 시각·OHLC 낙폭 상한이 달라질 수 있다.

동일 거래소의 신호·체결 자료만 결합한다. Binance1분에서1/3/5/15분 신호를 집계하여7코인28개6개월 조합을 비교한다. MEXC는 확보된1분 구간과 해당 거래소5/15분 원본 신호를 사용하며 짧은 기간으로 명시한다. 기간은2026-04-14 00:00→2026-10-14 00:00 KST 직전, 편도0.02%, 초기$1000·10배 전액 재투자다. 보수적 비용은 편도 총0.03%·S2 손절 추가0.05%이며 진입 규칙은 고정한다. 펀딩·공정가격 강제청산·최소 주문 수량은 제외한다.

대상 BTC/ETH/BNB/SOL/XRP, 비교 WLD/ZEC. 모든 성과는 이미 관측한 시장을 이용한 소급 연구다. 승률·손익비·PF·거래 수·순기대값·낙폭·자산0접촉과 미진입 원인을 기록하고, 코인별 최고 결과를 골라 공통 전략이라고 표현하지 않는다.

# PPP 조합 D–H의 사전 고정 가설

기존 C의 교차에 서로 다른 정보를 추가하면 진입의 질이 달라지는지 확인한다.
모든 조합이 효과적이라고 가정하지 않는다. 비교 전에 아래 값을 고정했다.

| 조합 | 주선·시그널 | 진입 추가 조건 |
|---|---|---|
| D | 기존 C | ADX(14,14) ≥ 20, +DI/−DI가 진입 방향과 일치 |
| E | 기존 C | MACD(12,26,9) 히스토그램이 롱에서는 양수·증가, 숏에서는 음수·감소 |
| F | 기존 C | MFI(HLC3,14)가 롱에서는 50 초과, 숏에서는 50 미만 |
| G | 기존 C | F + 현재 거래량 / 직전 20봉 평균 거래량 ≥ 1.2 |
| H | MACD(12,26,9) | RSI(종가,14)가 롱에서는 55 이상, 숏에서는 45 이하 |

기존 C의 설정은 가격 Stochastic 14 → EMA 5 → 최근 14봉 범위 재정규화
→ EMA 3 본선 → EMA 3 시그널이다. H는 Stochastic을 사용하지 않는다.
거래량 평균에 현재 봉을 넣지 않으며, 현재 봉의 확정된 거래량으로 신호를 판정한다.

SMA 20 > 50 > 100 > 200이면 롱만, 완전한 반대 배열이면 숏만 신규 진입한다.
배열·추가 필터는 진입에만 적용한다. D–G는 **필터링하지 않은 C 반대 교차**,
H는 필터링하지 않은 MACD 반대 교차에서 청산한다. 배열 변화나 필터 실패만으로
청산하지 않는다. 봉 마감에 신호를 만들고 다음 봉 시가로 체결한다.
손절·목표가·시간 제한·레버리지는 추가하지 않는다.

데이터·기간·비용은 [기존 검증 메모](ppp-sma-alignment.md)와 같다.
전체 시간봉의 6개월 비교는 Binance USD-M, MEXC 5·15분봉은 실제 6개월,
MEXC 1·3분봉은 별도 최근 기간이다. 수수료는 사용자 지정 편도 0.02%이며
슬리피지·펀딩비는 제외한다. 모든 비교에서 기존 C를 같은 비용으로 재계산한다.

앞 4개월과 뒤 2개월을 **독립적으로** 다시 실행해 시간에 따른 차이를 확인한다.
경계에 열린 포지션을 강제로 청산하거나 다음 구간으로 넘기지 않으므로 구간별
거래 수 합계가 전체 거래 수와 같지 않을 수 있다. 이전 분석에서 전체 기간을
이미 살펴봤으므로 뒤 2개월은 미관측 홀드아웃이라고 부르지 않는다.

승률, 청산 거래 수, 같은 진입 명목금액의 순이익/순손실 비율(PF), 거래당 평균
순손익, 월별·구간별 결과를 함께 비교한다. 거래 수의 C 대비 비율은 상대적인
거래 수이며 기존 C 거래가 그대로 일부 남았다는 의미가 아니다.
포트폴리오 최대 낙폭·증거금 위험은 이번 검증 범위에 포함하지 않는다.

구현은 `scripts/ppp_combo_backtest.py`와
`docs/tradingview/ppp-combinations`의 독립 Pine Script v6 파일이다.
재현 명령: `python3 scripts/ppp_combo_backtest.py --fee 0.0002`.
출력·거래 데이터는 무시되는 `user_data/backtest_results/ppp-combinations-2026-10-14`에 둔다.
새 조건을 결과에 맞춰 최적화하지 않는다. 실제 가격 구간에서 원본 Pine 실행과
수치·진입·원시 교차를 대조하고, 미래 봉 추가가 이전 계산을 바꾸지 않는지도 확인한다.

계산 정의: [ADX](https://www.tradingview.com/support/solutions/43000589099-average-directional-index-adx/),
[MACD](https://www.tradingview.com/support/solutions/43000502344-moving-average-convergence-divergence-macd-indicator/),
[MFI](https://www.tradingview.com/support/solutions/43000502348-money-flow-mfi/).

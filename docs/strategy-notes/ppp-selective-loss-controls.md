# PPP 전액 10배 · 선별 손실 청산

## 가설과 승인한 범위

이전 연구의 일괄 배분 축소는 낙폭을 줄였지만 종료 잔고도 크게 줄였다. 이번에는
진입 크기를 그대로 두고, 진입 직후 큰 역행이 발생한 거래만 추가 청산하면
기존 순이익을 대부분 보존하면서 큰 손실을 줄일 수 있다는 가설을 검증한다.
사용자는 아래 다섯 방식과 수수료·슬리피지 비교, 통합 HTML 갱신을 승인했다.

기존 진입의 해당 주기 SMA20/50/100/200 엄격한 정배열 롱·역배열 숏을 유지한다.
C는 이중 Stochastic, E는 C + MACD 모멘텀, G는 C + MFI 및 상대 거래량이다.
기존 청산은 C의 R0/R4, E의 R0, G의 R0/R2를 비교한다. R0는 반대 크로스,
R4는 추가 1.5 ATR 종가 손절, R2는 추가 SMA50 반대편 종가 청산이다.

## 손실 기록에서 확인한 점

MEXC ZEC 5분 G/R2 기준 기록의 307거래는 순이익 117거래·순손실 190거래다.
보유 봉의 1.5% 가격 역행은 손실 9거래와 이익 1거래에서 나타났다. 1% 역행은
손실 25거래와 이익 3거래였다. 최악의 −3.5519% 단위 순손실은 실제 진입 봉에서
크게 역행했다. 반면 +7.413% 순수익 거래의 1.5% 역행은 두 번째 보유 봉에서
나타났다. 따라서 전 보유 기간 손절과 첫 진입 봉에서만 작동하는 손절을 구분한다.
이 통계는 청산 시가 이후 고·저점을 제외한 사후 경로 분석이다.

큰 손실 직후 거래도 무조건 손실은 아니었다. 위 기준에서 −1%보다 큰 순손실
이후 다음 11거래의 평균 단위 순수익은 약 +1.0069%였다. 표본이 작아 반복 가능한
수익 규칙이라고 단정할 수 없지만, 손실 후 일괄 크기 축소를 이번 설계에 추가할
근거로 삼지 않았다. 손실을 사후에 미리 알고 진입을 취소하는 방식은 사용하지 않는다.

## 실행 전에 고정한 청산 규칙

| 코드 | 추가 규칙 |
|---|---|
| S0 | 기존 청산 유지, 전액 10배 기준 |
| S1 | 진입 가격 대비 1.5% 역행에 전량 손절, 보유 내내 작동 |
| S2 | 실제 진입 봉에 한해서 진입 가격 대비 1% 역행에 전량 손절 |
| S3 | 실제 진입 봉에 한해서 진입 가격 대비 1.5% 역행에 전량 손절 |
| S4 | 실제 진입 봉에 한해서 1% 역행에 최초 수량의 절반 청산, 나머지는 기존 청산 |
| S5 | 최초 두 보유 봉에서 진입 전 신호 봉의 저점 아래 종가(롱)·고점 위 종가(숏)가 나오면 다음 시가 전량 청산 |

S2–S4의 주문은 다음 봉 시작 전에 취소된다. S5의 기준은 실제 진입 전에 이미
확정된 **신호 봉**의 고·저점이다. 진입 봉의 미래 고·저점을 미리 사용하지 않는다.
추가 청산 후에는 다음 새 지표 교차가 있어야 재진입한다. S4는 남은 수량이 모두
청산되기 전에는 추가 진입하지 않는다. 익절·추적 익절은 추가하지 않는다.

## 체결과 시간

가격 손절은 실제 진입 시가부터 활성화된다고 가정한다. 보유 봉의 저점·고점이
손절가에 닿으면 손절가에 체결한다. 이후 봉 시가가 손절가를 넘어 불리하게 시작하면
해당 시가에 체결해 갭 손실을 포함한다. 원래 종가에서 주문한 기존 청산은 그 다음
시가에 먼저 체결되므로 해당 청산 봉의 이후 고·저점은 손절 탐색에 포함하지 않는다.
[TradingView 공식 체결 모형](https://www.tradingview.com/pine-script-docs/concepts/strategies/)도
갭으로 넘어간 주문을 봉 시가에 체결하는 가정을 설명한다.

봉 내부 손절의 정확한 tick 시각은 OHLC로 알 수 없다. 거래 CSV는 손절 봉 시작
시각과 결과를 사용할 수 있는 봉 마감 시각을 함께 기록한다. 추가 슬리피지 시나리오는
손절 체결 가격에만 0.05%를 불리하게 적용하며 S5의 추가 청산도 포함한다.
원래 반대 크로스·종가 청산에는 이번 추가 슬리피지를 적용하지 않는다. 이는 손절
민감도 비교이고 시장 전반의 실제 체결 비용 추정은 아니다.

S4는 최초 수량의 절반을 청산하며 남은 수량을 다시 확대하지 않는다. 진입 수수료는
전체 명목가치, 각 청산 수수료는 그 청산 수량의 실제 명목가치에 부과한다.
두 청산의 합을 한 원래 거래로 집계해 승률이 청산 횟수 증가로 부풀지 않도록 한다.
잔여 포지션이 마지막에 열려 있으면 실제 절반 청산 수익·수수료와 마지막 종가의
미실현 손익을 포함하고, 미청산 수량에 가상 청산 수수료를 붙이지 않는다.

## 자금과 비교 조건

각 조합은 독립 $1,000 계좌, 10배 계약, 출금·추가 입금 없이 전액 재투자다.
현재 자산 E, 편도 수수료 f=.0002에서 `N=E*10/(1+10*f)`의 명목가치로 진입한다.
수수료는 편도 0.02%, 최초 명목가치는 $9,980.04다. 정·역배열을 포함한 기존
진입 기회가 모두 보존되었는지는 24개 데이터셋의 전체 C 교차 배열이 번갈아
발생하는지 확인하는 검사로 제한한다. 같은 방향 연속 교차가 있으면 저널 재생을
거부한다. 이 조건은 일반적인 교차 지표의 보편 성질이 아니다.

기준 S0의 120개 조합은 이전 저장된 복리 잔고·폐쇄 낙폭과 일치해야 한다.
BTC/ETH/ZEC의 Binance 1·3·5·15분은 KST 2026-04-14 00:00부터
2026-10-14 00:00 직전까지의 6개월이다. MEXC는 5·15분의 같은 6개월과
1·3분의 더 짧은 자료를 분리한다. 기간은 새로 연장하지 않는다.

합격 기준은 원래 기준이 순이익인 경우에만 정의한다. **새 순이익 / 기존 순이익
80% 이상**, 폐쇄 거래 최대 낙폭 감소, OHLC 낙폭 상한 감소, 거래가격 평가자산
0 이하 접촉 없음이 모두 필요하다. 잔고 자체의 80%를 비교하는 것이 아니다.
MEXC ZEC 5분 G/R2의 기준 $23,288.46에서 하한은
`1000 + .8*(23288.46-1000)` ≈ **$18,831**다. 합격 후보가 없어도 그대로 보고한다.

## 성과 해석과 한계

손익비는 거래 시작 시점 자산 대비 평균 양수 순수익률 / 평균 음수 순수익률
절댓값이다. 전액 10배가 일정하므로 단위 가격 손익비와 계좌 손익비가 같다
(계좌가 0으로 제한되는 파산 경로는 별도 예외). 승률은 완결 거래만 사용한다.
기존 승자 중 손절된 거래와 기존 패자 중 좋아진·나빠진 거래를 별도로 기록한다.

폐쇄 낙폭과 보유 중 가격 평가자산 낙폭을 구분한다. OHLC 낙폭 상한은 알 수 없는
봉 내부 순서 중 유리한 극값이 손절 전에 발생할 수 있는 경우를 사용한다.
전량 손절 이후 봉의 추가 역행은 제외하고, 절반 손절 이후에는 잔여 수량의
역행을 계속 포함한다. 갭 시가 청산에는 청산 이후 고·저점을 포함하지 않는다.
따라서 정확한 실제 계좌 경로가 아니라 가능한 봉 경로에 대한 보수적 상한이다.

앞 4개월과 뒤 2개월은 각각 새 $1,000 계좌로 시작하고 이전 구간 포지션을
이월하지 않는다. 구간 마지막 미청산은 종가로 평가한다. 이미 전체 과거 자료를
살펴본 뒤 후보를 결정했으므로 뒤 2개월을 미관측 홀드아웃이라고 부르지 않는다.
자산·주기·기존 청산이 서로 겹친 결과의 합격 비율을 독립적인 성공 확률로 보지 않는다.

실제 공정가격 기반 강제청산·유지증거금·펀딩·최소 주문량·계약 수량 한도·유동성을
재현하지 않았다. 거래가격 평가자산 0 이하 접촉은 실제 강제청산 횟수가 아니다.
[MEXC 공식 설명](https://www.mexc.com/support/article/faq-on-liquidation-for-futures-trading-8123281969561).
0 이하 접촉이 있는 이론 수익 경로는 실제 계좌에서 계속 유지 가능한 성과로 보지 않는다.

# PPP C/E/G 리스크 관리 연구

## 가설과 범위

기존 패배 거래뿐 아니라 승리 거래의 경로도 분석해, 큰 손실을 줄이면서
평균 수익을 지나치게 훼손하지 않는 종가 기준 청산을 비교한다. 진입 신호는
바꾸지 않는다. 사용자는 C/E/G에 여섯 가지 방식을 적용하는 설계를 승인했다.

- C: 이중 Stochastic 본선/시그널 크로스.
- E: C + MACD(12,26,9) 히스토그램 방향·증가/감소 필터.
- G: C + MFI(14) 방향 + 현재 거래량/직전 20봉 평균 거래량 ≥ 1.2.
- 모든 롱 진입: `SMA20 > SMA50 > SMA100 > SMA200` 및 해당 모델 상승 크로스.
- 모든 숏 진입: 엄격한 역배열 및 해당 모델 하락 크로스.
- 이평선은 해당 차트 주기의 종가 SMA다. 혼합·동일 배열에서는 신규 진입하지 않는다.

## 청산 방식

모든 방식에서 필터 없는 C 반대 크로스는 반드시 청산한다. 같은 종가에서
반대 크로스와 리스크 조건이 겹치면 반대 크로스를 청산 사유로 기록한다.

| 코드 | 추가 리스크 조건 |
|---|---|
| R0 | 기존 반대 크로스 청산만 |
| R1 | 롱 종가 < SMA20 / 숏 종가 > SMA20 |
| R2 | 롱 종가 < SMA50 / 숏 종가 > SMA50 |
| R3 | 실제 진입 봉보다 나중 봉에서 롱 종가 < 진입 봉 저점 / 숏 종가 > 진입 봉 고점 |
| R4 | 롱 종가 < 진입가 − 1.5 ATR / 숏 종가 > 진입가 + 1.5 ATR |
| R5 | R2 또는 R3 중 먼저 종가에서 발생한 조건 |
| R6 | R5 + 수수료 후 1 ATR 수익에 도달한 다음 봉부터 본전 보호 |

이평선 조건은 반대편 종가 상태를 판정한다. 진입 직후부터 적용하며 별도의
이평선 교차 이력을 요구하지 않는다. 수준과 같은 종가는 손절 조건이 아니다.
손절이라는 이름의 구조적 청산이라도 체결 시점에는 이익으로 종료될 수 있다.

ATR은 Wilder RMA 방식의 ATR14이며 **진입 시가 직전 신호 봉의 확정 값**으로
고정한다. 실제 진입 봉의 고·저점은 그 봉이 끝나야 확정되므로 R3는 이후 봉의
종가부터 검사한다. 봉 내부 꼬리만 기준을 넘으면 R3 손절하지 않는다.

진입가 P, 편도 수수료 f, 방향 d(롱 +1 / 숏 −1)일 때 청산가 X의 순수익률은
`d*(X/P-1) - f*(1+X/P)`다. 수수료는 진입·청산의 실제 명목가치에 각각 적용한다.
R6은 현재 종가의 이 순수익률이 `진입 ATR/P` 이상이면 활성화된다. 활성화한
봉의 저·고점으로 소급 청산하지 않는다. 수수료 포함 본전 가격은
`P*(1+d*f)/(1-d*f)`이며, 이후 종가가 불리한 쪽으로 넘어가면 청산한다.

## 체결과 재진입

모든 신호는 종가 확인 후 **다음 봉 시가** 체결이다. 리스크 임계값을 지정가로
체결했다고 가정하지 않는다. 갭이 있으면 ATR 기준보다 더 크게 잃거나 본전 보호
청산에서 실제 순손실이 발생할 수 있다. 기간 끝에 다음 시가가 없는 조건은
체결하지 않는다. 미청산 포지션은 따로 기록하고 폐쇄 거래 지표에서 제외한다.

한 번에 한 포지션만 보유한다. 원래 반대 크로스 청산 시 신규 방향의 SMA 배열과
모델 필터가 모두 맞으면 같은 다음 시가에 반전할 수 있다. 리스크만 발동한 봉에서는
즉시 재진입하지 않고 이후의 새로운 적격 크로스를 기다린다. 따라서 진입 **조건**은
그대로여도 보유 시간이 달라져 거래 수와 진입 시점은 기준 전략과 달라질 수 있다.

## 데이터와 평가

기존 연구와 동일하게 KST 2026-04-14 00:00부터 2026-10-14 00:00 직전까지 평가한다.
BTC/ZEC USDT의 1·3·5·15분 전체 비교는 Binance USD-M의 실제 1분봉을 사용한다.
후속 요청으로 ETH USDT를 같은 주기와 동일한 고정 리스크 규칙에 추가했다. ETH를 보기
전에 선택한 여섯 방식의 기준값을 바꾸지 않는다. 리스크 없는 R0도 선택 후보로 포함하며,
특정 자산·주기에 리스크를 추가해 기대수익이 감소하면 기존 유지를 허용한다.
MEXC 선물 자체 데이터는 5·15분봉만 6개월이며, 1·3분봉은 KST 9월 14일 13:15 이후의
짧은 기간이다. 짧은 기간은 6개월 결과와 구분한다. 3분봉은 연속된 실제 1분봉으로
집계하며 빈 구간을 가격 복사로 채우지 않는다. 자세한 데이터 출처는 기존
[조합 연구](ppp-combinations.md)와 결과의 SHA-256 기록을 따른다.

편도 수수료는 사용자가 지정한 0.02%다. 펀딩·슬리피지·레버리지 청산은 제외한다.
다른 거래소 시세를 사용한 결과에도 같은 지정 수수료를 적용하므로 거래소 고유의
실제 수수료 성과로 해석하지 않는다.

- 승률: 수수료 후 양수인 폐쇄 거래 수 / 전체 폐쇄 거래 수.
- **실현 손익비**: 이긴 거래의 평균 순수익률 / 진 거래의 평균 순손실률 절댓값.
- Profit Factor: 양수 순수익률 합 / 음수 순수익률 합 절댓값. 손익비와 다른 지표다.
- 기대수익: 거래당 평균 순수익률. 승률만 높아진 결과를 채택하지 않도록 함께 본다.
- 손실 꼬리: 패배 거래 손실의 95백분위 및 최악 단일 거래.
- 낙폭: 폐쇄 거래마다 순수익률을 1배로 복리 적용한 모델의 최대 낙폭. 봉 내부
  평가손실·미청산 포지션·실제 증거금 관리가 반영된 계좌 낙폭과는 다르다.

손실 분석에는 실제 보유 중인 봉만 포함하고, **청산 봉은 시가에서 이미 나왔으므로
그 봉의 고·저점을 제외**하고 실제 청산 시가 체결가는 포함한다. 후보 조건 발동 비율은 사후 경로 설명이며 손실 회피
비율이나 재백테스트 수익이 아니다. 승리 거래의 같은 조건 발동도 함께 확인한다.
최악 10% 패배 거래의 손실 집중도는 가장 큰 손실 거래 수를 올림하여 계산한다.

여섯 방식과 ATR 배수는 백테스트 전에 고정했고 파라미터 격자 탐색을 하지 않는다.
다만 같은 6개월 기록을 보고 후보를 결정했으므로 성과는 사후 연구다. 앞 4개월과
뒤 2개월을 각각 처음부터 별도 시뮬레이션해 시기별 비교를 하며, 이를 미관측
검증 표본이라고 부르지 않는다. 자산·주기별 최고값 선정도 같은 표본 내 선정이다.

## 재현과 확인

`scripts/ppp_risk_backtest.py`가 기존 공통 지표·진입 게이트를 재사용한다. R0는
기존 엔진으로 같은 비용에서 재계산한 **전체 거래 기록과 정확히 같음**을 검사한다.
기본 비용에서는 기존 저장 결과의 승리 수·거래 수까지 일치해야 한다.

```bash
python scripts/ppp_risk_backtest.py --fee 0.0002
python scripts/ppp_risk_report.py
python -m unittest discover -s tests -v
```

런타임 산출물은 git에서 제외된 `user_data/backtest_results/ppp-risk-2026-10-14/`에
저장한다. 결과 JSON, 전체 거래 CSV, 사후 경로 진단, 승률·손익비 보고서를 제공한다.
검증은 다음 시가 갭, 실제 진입 봉 수준, ATR 고정, 수수료 포함 본전, 종가와 꼬리
구별, 재진입, 반대 크로스 우선순위, 시간 인과성, 손익비와 PF 구별을 다룬다.

이 연구는 사용자 요청의 독립 백테스트 검증이며 Freqtrade 실거래 전략 변경이 아니다.

## ETH 확장과 10배 복리 계산

ETH 데이터는 기존 BTC/ZEC 파일·매니페스트를 덮어쓰지 않도록 별도
`user_data/data/ppp-binance-eth/`와 `ppp-mexc-eth/`에 저장했다. Binance ETH의
281,700개 실제 1분봉은 체크섬·경계·OHLCV 검증을 거친다. MEXC의 짧은 1·3분
평가 시작은 최소 600개 실제 1분봉 준비 구간을 확보한 후 UTC 15분 경계로 정한다.
기존 BTC/ZEC 평가 시작은 같다. 새 결과의 기존 BTC/ZEC 336개 레코드는 이전
결과와 필드별로 정확히 같음을 확인한다.

```bash
python scripts/ppp_binance_download.py --symbols ETHUSDT --output user_data/data/ppp-binance-eth
python scripts/ppp_mexc_download.py --symbols ETH_USDT --output user_data/data/ppp-mexc-eth
python scripts/ppp_risk_backtest.py --assets BTC ETH ZEC --output user_data/backtest_results/ppp-risk-eth-2026-10-14
python scripts/ppp_risk_report.py --output user_data/backtest_results/ppp-risk-eth-2026-10-14 --plots
python scripts/ppp_capital_replay.py --output user_data/backtest_results/ppp-risk-eth-2026-10-14 --initial 1000 --leverage 10
```

복리 질문은 **각 자산·주기·모델·리스크 조합별 독립 계좌**가 $1,000에서 시작해,
매번 잔고 전액을 10배 포지션의 증거금으로 재투자하는 모형으로 해석한다. 여러
전략을 하나의 $1,000 계좌에서 동시에 운용하는 포트폴리오 결과가 아니다.
진입 수수료까지 잔고 내에서 감당하도록 주문 명목가치를 `잔고*10/(1+10*f)`로
정한다. 매 거래 뒤 `새 잔고 = 잔고 + 주문 명목가치 * 거래 순수익률`로 갱신한다.
출금·추가 입금은 없다. 평균 수익률에 거래 수를 곱하거나 전체 수익을 10배 하지 않는다.

기간 말 열린 포지션은 진입 수수료와 마지막 종가의 평가손익을 반영해 종료 평가자산을
별도로 기록한다. 실제로 청산하지 않았으므로 가상의 청산 수수료를 차감하지 않는다.
폐쇄 거래 최대 낙폭과 거래가격 OHLC를 이용한 낙폭 상한을 구분한다. OHLC 상한은
봉 안에서 유리한 고·저점 이후 불리한 고·저점이 나온 것으로 보는 보수적인 순서다.
실제 청산 시가의 갭도 반영하며 이후 청산 봉의 꼬리는 제외한다.

이 계산은 **강제청산·펀딩·슬리피지·주문 단위/한도를 제외한 이론 잔고**다.
[MEXC 공식 강제청산 설명](https://www.mexc.com/support/article/faq-on-liquidation-for-futures-trading-8123281969561)에
따르면 공정가격이 강제청산을 발동시키며 유지증거금과 청산 수수료가 필요하다.
과거의 전체 공정가격·위험등급 변경 이력이 없으므로 일반 OHLC만으로 실제 강제청산을
확정하지 않는다. 거래가격 기준 평가자산 0 이하 접촉은 별도 표시하여, 그 뒤의
이론적인 복리 잔고를 실제 운용 가능한 성과로 읽지 않도록 한다.

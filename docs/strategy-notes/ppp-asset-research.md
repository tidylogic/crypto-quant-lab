# 다른 자산의 PPP C/E/G 반복 연구

가설: ZEC에서 비교한 고정 C/E/G 진입 규칙과 R0–R6 종가 청산 규칙이 다른 자산에서도 같은 비용·체결 가정으로 어떤 거래 수, 승률, 손익비와 낙폭을 만드는지 비교한다. 새 자산 결과로 규칙이나 문턱을 조정하지 않는다.

`scripts/ppp_asset_research.py`는 기존 지표·리스크·계좌 함수를 사용한다. 코인, 자료 디렉터리, 기간, 모델, 청산 방식, 편도 수수료, 초기 자금과 레버리지를 CLI로 받는다. 다운로드는 기존 거래소별 스크립트의 `--symbols` 옵션으로 별도 수행한다. 실제 OHLCV 파일과 결과물은 git에서 제외되는 `user_data/data`, `user_data/backtest_results`에 둔다.

- 공통: SMA20 > SMA50 > SMA100 > SMA200이면 롱, 반대 역배열이면 숏. 확정 C 교차와 모든 진입 필터가 같은 봉에서 통과해야 다음 시가에 진입한다.
- C: 이중 Stochastic 교차만 사용한다.
- E: C + MACD12/26/9 히스토그램이 롱은 양수·전봉보다 상승, 숏은 음수·전봉보다 하락해야 한다.
- G: C + MFI14가 롱 >50, 숏 <50이며 현재 거래량/직전20봉 평균 거래량 >=1.2를 요구한다.
- R0–R6: `ppp_risk_backtest.PROFILES`의 기존 고정 규칙이다. 반대 교차 청산은 필터 없이 항상 유지한다. 리스크만으로 청산한 봉에서는 재진입하지 않는다. 같은 다음 시가의 반대 교차 청산과 조건 충족 반전 진입은 허용한다.
- 각 조합은 독립 계좌다. 편도0.02%, $1,000, 전액10배, 출금 없는 복리를 기본으로 한다. 승률·손익비는 종료된 전략 거래 기준이며 손익비는 1배 순수익률의 평균 승자/평균 패자다. 실제 계좌 주문 수량은 재현하지 않는다.
- 펀딩·슬리피지·공정가격 강제청산·계약/주문 수량 제한은 제외한다. OHLC 가격 평가자산0접촉은 실제 강제청산 횟수가 아니다. 접촉 후 계산된 복리 경로를 지속 가능한 실거래 결과로 해석하지 않는다.

전략별 HTML 하나에 모든 거래소·주기와 R0–R6 비교표, 전체 기간 캔들, 수익·손실 거래, 연속 손실 선택, 날짜 이동과 진입 조건 진단을 포함한다. E에는 MACD, G에는 MFI/RVOL, R4/R6에는 ATR을 표시한다. 기본 C/R4, E/R0, G/R2는 기존 ZEC 비교 설정을 그대로 사용한 것이며 새 자산에서 가장 잘 나온 설정을 자동 선택한 결과가 아니다.

HTML은 거래소·주기별로 데이터를 압축해 넣고 선택된 자료만 해제한다. 모든 실제 봉을 유지하며 지표 표시 반올림으로 진입 판정을 계산하지 않는다. 판정 비트는 엔진의 9자리 비교에서 가져오고, 포지션과 진입·청산 마커는 전체 원본 거래 기록에서 재구성한다. `/tmp`나 이전 채팅 파일을 생성 입력으로 사용하지 않는다. 재사용 템플릿과 고정 차트 라이브러리는 `scripts/templates`, `scripts/vendor`에 보관한다.

예시:

```bash
python scripts/ppp_asset_research.py --asset WLD \
  --binance-data user_data/data/ppp-binance-wld \
  --mexc-data user_data/data/ppp-mexc-wld \
  --start 2026-04-13T15:00:00Z --end 2026-10-13T15:00:00Z \
  --output user_data/backtest_results/ppp-wld-2026-10-14
```

Binance 1분을 완전한 1/3/5/15분봉으로 집계한다. MEXC 5/15분은 원본 자료를 사용하고, 짧은 1분 이력은 없는 봉을 만들지 않고 600분의 워밍업 후부터 1/3분을 별도 기간으로 평가한다. 각 자료는 평가 기간의 완전한 연속성과 최소 200개의 사전 봉을 검증한다.

## ZEC 최고 수익 설정의 다른 자산 검증

가설: ZEC 5분 G/R2에서 최고 종료 자산을 기록한 S2를 새 자산에도 고정 적용해 수익 보존과 낙폭 개선 여부를 비교한다. 1%라는 문턱을 새 자산 결과로 조정하지 않는다.

`scripts/ppp_asset_selective.py`는 기존 결과의 G/R2 거래와 원본 자료 체크섬을 검증한 뒤 기존 `apply_policy`와 `replay_selective`를 그대로 재사용한다. S2는 실제 진입 봉에서만 롱 진입가×0.99 / 숏 진입가×1.01에 전량 가격 손절하며 다음 봉 전에 취소한다. 이후 반대 교차·SMA50 종가 청산을 유지한다. 진입 크기·지표·정역배열·비용은 입력 연구의 설정을 유지한다.

기준 S0와 S2(추가 손절 비용 없음), S2(손절 체결에만 추가0.05%)를 비교한다. 기본 S0의 자산·낙폭·거래 수가 입력 결과와 일치해야 한다. 보존한 원래 진입 기회가 실제 지표의 모든 조건과 맞는지, 전체 원시 교차가 번갈아 발생하는지 확인한다. 이 보존 조건을 통과하지 않는 자산은 저널 재생을 거부한다.

봉 내부 손절의 정확한 체결 tick은 알 수 없다. 마커는 해당 진입 봉에 표시하지만 잔고 변화는 그 봉 마감부터 알려진 것으로 기록한다. 같은 봉 안에서 진입·청산된 거래에 허구의 다음 시가 청산을 그리지 않는다. 마지막 평가 봉 내부에서 실현된 손익은 종료 시각에 계좌지수 점을 추가하며, 가격 캔들을 추가하지 않는다. 손절 후 이후의 새 교차에는 진입할 수 있지만 같은 이전 신호를 재사용하지 않는다.

```bash
python scripts/ppp_asset_selective.py \
  --input user_data/backtest_results/ppp-wld-2026-10-14 \
  --output user_data/backtest_results/ppp-wld-s2-2026-10-14
```

기존 결과 파일은 보존하고 별도 디렉터리에 기준과 S2를 선택할 수 있는 G HTML, 모든 주기의 비교표, 요약·거래 CSV 및 감사 자료를 생성한다.

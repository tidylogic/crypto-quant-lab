# PPP 시안 + SMA 배열 가설

## 가설

PPP 시안의 교차를 SMA 20·50·100·200의 완전한 배열로 제한하면,
혼합된 추세에서 발생하는 진입을 줄일 수 있다는 가설을 검증한다.
원본 PPP의 공식은 미확인이므로 A·B·C를 각각 독립적인 가설로 취급한다.
이 메모는 사용자가 요청한 별도의 수치 검증을 재현하기 위한 규칙 기록이다.

## 고정 규칙

- 롱: 해당 봉의 종가로 계산한 `SMA20 > SMA50 > SMA100 > SMA200`와 본선의 시그널선 상향 교차.
- 숏: `SMA20 < SMA50 < SMA100 < SMA200`와 하향 교차.
- 혼합 배열 또는 하나라도 같은 값이면 신규 진입하지 않는다.
- 롱의 하향 교차, 숏의 상향 교차에서는 배열에 관계없이 청산한다.
- 배열만 바뀌어서는 청산하지 않는다. 손절·목표가·최대 보유 시간은 추가하지 않는다.
- 모든 신호는 봉 마감에 계산하고 다음 봉 시가에 체결한다.
- 모델·종목·시간봉별로 한 포지션만 보유한다. 청산 봉에서 반대 방향 배열도 성립하면 같은 시가로 반전할 수 있다.
- 평가 구간의 봉에서 나온 신호만 사용한다. 구간 이전 포지션을 이월하지 않는다.
- 마지막에 반대 교차로 청산되지 않은 포지션은 승률에서 제외하고 따로 기록한다.

## 비교 설정

A: RSI 14, 정규화 범위 14, 본선 SMA 3, 시그널 SMA 3.
B: 가격 범위 14, 본선 SMA 3, 시그널 SMA 3.
C: 가격 범위 14, 1차 EMA 5, 2차 범위 14, 본선 EMA 3, 시그널 EMA 3.
원본에서 추정한 기본값이며, 이번 결과를 보고 최적화하지 않는다.
세 시안의 과매수·과매도 교차 필터는 꺼 둔다.

평가 기간은 한국 시간 2026-04-14 00:00부터 2026-10-14 00:00 전까지다.
사용자 지정 수수료는 편도 0.02%다. 진입·청산 각각 실제 가정 체결 금액에 부과한다.
슬리피지·펀딩비·레버리지·강제 청산은 반영하지 않는다.

## 데이터와 재현

Binance USD-M 공개 1분봉을 원본으로 UTC에 맞춰 3·5·15분봉을 생성한다.
MEXC는 공식 API의 5·15분봉을 직접 사용하고, 확보한 최근 1분봉을 3분봉으로 합친다.
MEXC 1·3분봉의 짧은 평가 기간을 6개월 비교에 섞지 않는다.
데이터를 상향 보간하거나 다른 거래소 가격을 MEXC로 표시하지 않는다.

- `scripts/ppp_binance_download.py`: 공식 공개 아카이브와 최신 REST 데이터, 체크섬 검증.
- `scripts/ppp_mexc_download.py`: 공식 API 응답과 조회 경계, 누락·OHLC 감사.
- `scripts/ppp_backtest.py`: 고정 계산식, 배열·교차 규칙, 거래별 비용 및 승률.
- `tests/test_ppp_backtest.py`: 다음 시가 체결, 숏 비용, 반전, 미청산 포지션, 누락 봉 처리 검증.

실행: `python3 scripts/ppp_backtest.py --fee 0.0002`.
NumPy가 있는 Python 환경과 다운로드된 CSV가 필요하다.
다운로드·생성 결과는 무시되는 `user_data/data/ppp-*`와
`user_data/backtest_results/ppp-2026-10-14`에 둔다.

## 해석 범위

승률은 수수료 후 손익이 양수인 청산 거래 수 / 전체 청산 거래 수다.
수수료 전 승률도 같은 거래 표본으로 계산한다. PF는 동일한 진입 명목금액을
가정한 양수 순수익률 합계 / 음수 순수익률 합계의 절댓값이다.
포트폴리오 수익률·최대 낙폭·증거금 위험을 측정한 결과가 아니다.

계산식은 실제 MEXC 5분봉 표본에서 PineTS의 원본 Pine 실행값과 교차 위치를 대조한다.
PineTS 검증은 TradingView 자체 컴파일·실제 체결과 별개의 검증이다.
EMA 초기화 차이는 충분한 선행 봉 후 평가 기간 교차에 영향을 주는지 별도로 확인한다.

참고: [MEXC 캔들 API](https://www.mexc.com/api-docs/futures/market-endpoints/get-candlestick-data),
[Binance 공개 데이터](https://github.com/binance/binance-public-data),
[TradingView 과거 분봉 제한](https://www.tradingview.com/support/solutions/43000480679-historical-intraday-data-bars-and-limits-explained/).

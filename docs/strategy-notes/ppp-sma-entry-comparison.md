# 추세·거래량: SMA30·60·120·240과 두 진입 방식

## 가설과 고정 비교

사용자가 지정한 새 SMA30/60/120/240이 기존20/50/100/200보다 배열과 눌림목 확인에 유리한지 비교한다. 신호는 활성 추세·거래량 G의 이중 Stochastic 새 교차, MFI14 롱>50/숏<50, 이전20봉 대비 RVOL≥1.2를 유지한다. 다른 사진 재현 PPP와 별도의 실험이며 G/R2+S2 기준을 교체하지 않는다.

| 항목 | 즉시 진입 | 지지·저항 확인 진입 |
|---|---|---|
| 원 신호 | 기준 타임프레임 봉 마감의 G 신호·엄격한 SMA 배열 | 동일 |
| 실제 진입 | 신호 마감 직후 다음1분봉 시가 | 이후1분봉 접촉·종가 회복 확인 후 다음1분봉 시가 |
| SMA 배열 | 롱 빠른 선>다음 선>다음 선>느린 선, 숏 반대 | 실제 진입 확인에도 같은 배열 필요 |
| 일반 청산 | 기준 봉 종가의 두 번째 SMA 실패 또는 원 지표 반대 교차 → 다음1분 시가 | 동일 |
| 별도 가격 손절 | 실제 진입이 포함된 기준 봉의1% S2 장중 손절 | 동일 |

20세트의 일반 손절선은 SMA50,30세트는 SMA60이다. 기존 지지 확인 연구의 진입 근거선/최근접선 청산과 달리, 이번에는 진입 방식 비교를 위해 두 모드의 청산을 같은 두 번째 SMA로 맞춘다. 손절의1분 마감/기준 봉 마감을 추가로 비교하는 실험이 아니다.

확인형은20→50→100→200 또는30→60→120→240 순서로 진입 전 대기한다. 허용 폭은 신호 당시 ATR14×0.1, 신호 유효기간은3개 기준 봉이다. 롱은1분 고저가가 선±허용 폭에 접촉하고 종가≥선+폭·양봉이면 회복, 숏은 대칭이다. 다음 선으로 넘어간1분봉의 과거 꼬리를 확인에 재사용하지 않는다. 반대 교차·배열 파괴·기한 만료·가장 느린 선 실패는 대기를 취소한다. 신호당1회 진입이며 손절 후 다음 선 재시도는 추가하지 않는다. 이 숫자들은 기존 고정값으로, 코인별로 최적화하지 않는다.

## 데이터·비용·결과 해석

2026-04-14 00:00→2026-10-14 00:00 KST, 종료 시각 미포함. BTC/ETH/BNB/SOL/XRP/WLD/ZEC의 Binance USDT 무기한1분 원본으로1·3·5·15분 신호를 만든다. MEXC는 동일 거래소의 확보된 짧은1분 구간과5·15분 신호만 별도로 비교한다. 신호·체결 가격을 거래소 간에 섞지 않는다. 준비 봉은 최대 SMA기간에 맞게240봉 이상 확보한다.

기본 편도0.02%, 비용 강화 편도0.03%·S2 손절 추가0.05%. 초기$1000·10배 전액 복리의 독립 계좌다. 펀딩·일반 체결 슬리피지·공정가격 강제청산·최소 계약수량은 제외한다. 기간 끝에서는 새 체결을 만들지 않고, 미청산 포지션은 마지막 종가로 평가하며 종료 거래 승률에서 제외한다.

승률·손익비·PF는 수수료 후 전체 전략 종료 거래를 사용하고, 실제 자금 실행 거래와 구분한다. 합산 승률은 거래 수 가중이며 PF는 총 단위 이익/총 단위 손실이다. 코인별 PF나 승률의 단순 평균이 아니다. 합산 통계는 공동 자금 포트폴리오 수익률이 아니다. 계좌 종료 자산·폐쇄 낙폭·OHLC 낙폭 상한·자산0접촉과 함께 거래 수·노출 시간·진입 대기·기한 만료를 보고한다. 적은 거래로 줄어든 낙폭을 타점 개선으로 단정하지 않는다.

2 SMA세트×2 진입 방식×36 시장·시간봉×2 비용=288개다. 기존20세트 즉시형72개는 보관된 기준형과 대조한다. 입력 해시와 거래·체결·순손익 불변식을 검증한다. 차트는 계산된 결과와 재계산한 거래·계좌 상태가 일치해야 생성한다.

## 완료 결과

288개 결과와75,956개 포지션 기록을 계산했다. 기존 기준형72개가 모두 일치했고,36개 시장·주기와19개 입력 파일 해시를 검증했다. 별도 검토에서 전체 거래 원장으로288개 개별 지표·잔고·폐쇄 낙폭,64개 합산 통계를 재계산해 일치했다. 기록에는 두 SMA·진입·비용 비교가 중복되므로 독립적인75,956거래라는 뜻이 아니다.

코인×SMA세트14개 차트 페이지의144개 프로필은 거래·계좌 상태가 계산 결과와 일치했다. 모바일 브라우저에서는15개 차트 선택·16개 보고서 필터, 실제 거래 행 터치 후 목록 유지, SMA60 청산 설명을 검증했다. 실제 세로 스와이프로 하단 지표·목록 복귀, 가로 팬·확대 유지도 통과했다. 전체 저장소 테스트246개는 실패 없이 완료했고 환경 의존6개는 제외했다. 이번에 저장하는 파일만 분리한 환경에서는132개 테스트가 모두 통과했다.
